# 动画播放可用性

没有动画片段、只有单个姿态或占位动画栈时，模型预览隐藏播放、逐帧和时间轴，释放预览空间。支持添加外部动画的模型仍保留工具栏/菜单入口；外部动画拒绝、参考骨架等真实诊断继续显示，不为隐藏播放控件而清空错误。

### v0.2 动画检查器

- 从视口标题或右侧检查器选择「动画」。下方时间轴和检查器共享片段选择、速度、循环和根运动状态。检查器中可输入正数倍速，按回车确认。
- 需要定格时，拖动时间轴或点击上一帧、下一帧。播放会暂停在目标时间，步进长度取当前片段的源帧率。
- 对可以挂接外部动作的模型，尚无内置动作时也能进入「动画」并选择「添加外部动画」。可以继续使用模型标题栏的同一入口。PSK 选择 PSA，支持外部 FBX 的模型选择 FBX。配对结果由实际读取和映射决定。
- 有根节点时可在检查器选择要锁定的根。开启锁定后可选动画首帧、参考姿态或零点，参考姿态取决于模型提供的数据。未映射的根会显示原因。锁定只影响当前预览。

### 可播放片段的判定

可播放片段要求有限的起止时间、有限正时长及有效帧率。FBX额外检查片段层中绑定属性的曲线是否有至少两个不同时刻的键，避免仅凭Unreal Take等栈名或声明的时间范围误判。PSA使用源帧数大于一帧判断；其单帧片段可能仍声明一个帧间隔，不能只检查时长。判断来自解析数据，不使用扩展名白名单。多键保持不动的动画仍是有效时间片段；本判断不试图比较每帧画面。

原`animated`继续描述文档的动画求值能力；新增`hasPlayableAnimation`描述是否存在可播放片段，`canPlayAnimation`描述当前片段是否可播放。保留所有源片段及原索引；打开时优先选中名为 `Idle` 的可播放片段，否则选择源顺序中首个可播放片段，手动选择单姿态片段时停止计时器，片段选择器仍可切回有效片段。播放、步进、seek、菜单、Space快捷键、计时器和跨资源自动恢复均使用同一门槛。

零时长FBX原来在循环播放时用极小的替代时长取模，产生稍大于0的时间，超出唯一合法采样时刻。现在这种片段不能启动播放；可播放片段按真实时长循环。静态姿态采样和正常模型检查保留，读取/求值/渲染失败仍按原机制报告。

ABC使用独立几何缓存采样时间轴，不依赖骨骼片段；多采样可播放，单采样保持原有明确禁用状态。本项不修改ABC播放实现。

验证使用自生成小型glTF/FBX夹具，生成命令：`py tests/generate_animation_fixtures.py <输出目录>`；桌面回归通过`FORMAVIEW_PLAYBACK_FIXTURES`指定目录。`modelAnimationCapability`覆盖无效数值和混合片段，`modelAnimationAvailability`覆盖隐藏/恢复、重复直接调用和Space、索引、资源切换、正常glTF/FBX、真实拒绝/读取错误及单样本ABC；原ABC多样本回归另行执行。可选`FORMAVIEW_PROBE_PLAYBACK=1`让model_probe记录250ms播放状态，用于同一真实素材的修复前后对比。

外部证据目录：`asset-preview-planning/development/verification/M12.5-ui-20261112/`。软件离屏测试只证明状态、CPU帧与布局；原生GPU、任务栏缓存和多屏DPI验收另计。

最终Release的主程序、桌面测试、model_probe均构建成功。设置`FORMAVIEW_SKINNING=cpu`运行上述两项动画回归、ABC多采样和前三项回归，共15通过、0失败/跳过（6303ms，包含初始化/清理），见`animation-final-1/tests.txt`；软件离屏没有QRhi，截图仅作布局证据。10素材播放探针及独立JSON断言通过，真实`SM_Ring_01.FBX`不再启动错误播放，文件哈希、280点/490三角形保持一致；正常glTF、FBX和两帧PSA仍可播放。

「动画」检查器可查看目标模型和动作来源。支持配对的模型可直接选择外部动作文件，查看配对结果或移除外部动作。

在「动画」检查器输入速度后，按 Enter 确认。零、负数和无效文本会标出错误，并保留当前播放速度；按 Esc 恢复已生效的数值。时间轴上的片段选择器可通过悬停查看完整片段名。

### 区分多个动作文件

给同一目标追加 FBX 或 PSA 动作文件后，时间轴和「动画」检查器的片段名称旁会显示来源文件名。悬停可查看完整路径，所以不同目录的同名文件也能区分。切换片段时，检查器同步显示所选片段的来源。内置片段仍使用原名。PSK 配对多个 PSA 可用 `modelPskExternalAnimationDrive` 回归，含内置动画的 FBX 追加动作可用 `modelFbxNativeAnimation` 回归。

在「动画」检查器中切换「地面网格」，视口工具栏也会同步。用户可以在查看根运动时显示地面参照，也可以在定格检查姿态时关闭。

片段选择器在异步创建和列表刷新后重新绑定实际片段索引，避免 Qt 下拉框初始化把显示重置为第一项。CPU 与 GPU 的连续切换回归之后，均检查检查器选择、地面网格联动、播放、暂停与拖动定位；多个 PSA 的来源提示和实际姿态另行对照。


时间轴和「动画」检查器中选择片段时，会停止播放并定格在所选片段的起点，与 HTML 原型一致；重新选择当前片段也会回到起点。点击播放后才继续推进。modelAnimationInspectorControls 同时覆盖两个选择器，检查播放中的选择操作确实停止并归零到片段起点。
