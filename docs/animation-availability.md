# 动画播放可用性

没有动画片段、只有单个姿态或占位动画栈时，模型预览隐藏播放、逐帧和时间轴，释放预览空间。支持添加外部动画的模型仍保留工具栏/菜单入口；外部动画拒绝、参考骨架等真实诊断继续显示，不为隐藏播放控件而清空错误。

可播放片段要求有限的起止时间、有限正时长及有效帧率。FBX额外检查片段层中绑定属性的曲线是否有至少两个不同时刻的键，避免仅凭Unreal Take等栈名或声明的时间范围误判。PSA使用源帧数大于一帧判断；其单帧片段可能仍声明一个帧间隔，不能只检查时长。判断来自解析数据，不使用扩展名白名单。多键保持不动的动画仍是有效时间片段；本判断不试图比较每帧画面。

原`animated`继续描述文档的动画求值能力；新增`hasPlayableAnimation`描述是否存在可播放片段，`canPlayAnimation`描述当前片段是否可播放。保留所有源片段及原索引；混合资源首次选择有效片段，手动选择单姿态片段时停止计时器，片段选择器仍可切回有效片段。播放、步进、seek、菜单、Space快捷键、计时器和跨资源自动恢复均使用同一门槛。

零时长FBX原来在循环播放时用极小的替代时长取模，产生稍大于0的时间，超出唯一合法采样时刻。现在这种片段不能启动播放；可播放片段按真实时长循环。静态姿态采样和正常模型检查保留，读取/求值/渲染失败仍按原机制报告。

ABC使用独立几何缓存采样时间轴，不依赖骨骼片段；多采样可播放，单采样保持原有明确禁用状态。本项不修改ABC播放实现。

验证使用自生成小型glTF/FBX夹具，生成命令：`py tests/generate_animation_fixtures.py <输出目录>`；桌面回归通过`FORMAVIEW_PLAYBACK_FIXTURES`指定目录。`modelAnimationCapability`覆盖无效数值和混合片段，`modelAnimationAvailability`覆盖隐藏/恢复、重复直接调用和Space、索引、资源切换、正常glTF/FBX、真实拒绝/读取错误及单样本ABC；原ABC多样本回归另行执行。可选`FORMAVIEW_PROBE_PLAYBACK=1`让model_probe记录250ms播放状态，用于同一真实素材的修复前后对比。

外部证据目录：`asset-preview-planning/development/verification/M12.5-ui-20261112/`。软件离屏测试只证明状态、CPU帧与布局；原生GPU、任务栏缓存和多屏DPI验收另计。

最终Release的主程序、桌面测试、model_probe均构建成功。设置`FORMAVIEW_SKINNING=cpu`运行上述两项动画回归、ABC多采样和前三项回归，共15通过、0失败/跳过（6303ms，包含初始化/清理），见`animation-final-1/tests.txt`；软件离屏没有QRhi，截图仅作布局证据。10素材播放探针及独立JSON断言通过，真实`SM_Ring_01.FBX`不再启动错误播放，文件哈希、280点/490三角形保持一致；正常glTF、FBX和两帧PSA仍可播放。
