# 文件显示方式

文件区使用一个“文件显示方式”下拉框选择列表、缩略图和平铺。列表保留原双行文字，缩略图保留原网格；平铺把48px预览或类型图标放在左侧，右侧显示文件名、类型和大小。平铺随窗格宽度从一列扩展为多列。三种模式保留选择、右键、双击和键盘导航，切换时保留逻辑滚动位置。

设置以稳定枚举值 `list / thumbnails / tiles` 持久化为 `fileViewMode`，默认列表。首次读取旧设置时，`thumbnails=true`映射到缩略图，false/缺省映射到列表；读取时不额外写盘，下一次设置变更会保存规范值。非法新值拒绝写入，非法存储值按旧值或列表回退。旧布尔调用仍可切换列表/缩略图；平铺同步旧值为false，旧版回退为列表。翻译和显示顺序不影响存储值。

下拉框可Tab聚焦，上下键切换，Alt+Down展开后选择，Escape取消菜单。平铺左右键按项、上下键按实际列数移动；Ctrl/Shift多选保持原语义。窄窗使用一列并截断长文字。列表和网格仅实例化可见窗口，平铺复用异步缩略图和原有缓存预算，不一次创建整个大目录。

Release桌面回归覆盖设置迁移/重建后持久化、非法值、三种模式的10024项虚拟化（可见委托少于150）、窄宽布局、逻辑位置9000的滚动恢复、选择保持、选择器上下键、平铺按列键盘移动及翻译稳定性。测试写入176/600px宽度，工作区按既有规则限制为220..400px，实际文件窗格216/396px；平铺分别为一列/两列。三种模式分别验证目录重置为空/缩小期间的异步委托安全。首轮共11通过、0失败/跳过，包含图标回归和初始化/清理。

证据位于仓库外`asset-preview-planning/development/verification/M12.5-ui-20261112/`的构建日志、`views-1/tests.txt`与`desktop-evidence.json`。测试使用Qt 6.12.0离屏软件渲染及隔离设置，不等于原生Windows/GPU验收。真实Windows资源管理器界面不是本软件依赖；此处采用其平铺信息布局。原生多屏DPI、屏幕阅读器及GPU视觉仍需人工验收。
