# FormaView 应用图标

图标是透明背景上一个摆 T-pose 的人偶，腰间穿过一条莫比乌斯环形成的无限符号。人偶代表角色模型和骨骼绑定检查，莫比乌斯环代表动画循环与 3D 检视：环的一股从身体后方绕过，另一股从髋部前方穿过；左侧的半扭转让环带翻面，用深橙与浅橙两种色调区分朝向。没有底板、进度条或取景框；也不表达 GIF 拆帧、摄像机轨迹或 FOV 等尚未完整可用的功能。颜色取自 `Theme.qml` 的 `accent` 橙色系和产品已有的奶油色。

小尺寸单独布局：16–32px 使用更宽的环带、更大的人偶，去掉环带描边；40px 及以上使用完整布局。

`src/host/icons/formaview.svg` 是完整布局的矢量源。运行 `py -3 tools/generate_app_icon.py` 会生成 SVG，以及含 16、20、24、32、40、48、64、128、256px 图层的 Windows `formaview.ico`。每个 ICO 图层按各自布局超采样后单独缩放，不从 256px 图层缩小。

回归命令：`py -3 -B tests/app_icon_tests.py`。测试检查：
- SVG 与生成器输出一致，没有背景矩形，按“环后段、人偶、环前段”的顺序分层；
- 环带是单侧曲面，并同时呈现正反两种色调；
- 每个 ICO 图层与生成器逐像素一致，四角透明，主体居中；
- 各尺寸使用正确的布局。

Windows 资源管理器、任务栏和旧快捷方式可能缓存先前图标；本更改不清理系统图标缓存或重建用户快捷方式。
