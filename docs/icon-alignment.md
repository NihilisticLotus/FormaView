# FormaView 应用图标

图标是深色圆角底板上的一个等轴测立方体，四周是取景框四角，下方是一条带播放头的时间轴。立方体代表 3D 模型，顶面的 2×2 奶油色棋盘格代表图片与贴图，取景框表示预览与检查，时间轴表示动画的播放与拖动。图标不表达 GIF 拆帧、摄像机轨迹或 FOV 等尚未完整可用的功能。底板与立方体颜色取自 `Theme.qml` 的深灰和 `accent` 橙色三档明暗。

小尺寸单独布局：24–32px 去掉取景框四角并放大立方体、加粗时间轴；16–20px 只保留带棋盘格的立方体。

`src/host/icons/formaview.svg` 是 40px 及以上完整布局的矢量源，运行 `py -3 tools/generate_app_icon.py` 会按相同几何生成 SVG 和含 16、20、24、32、40、48、64、128、256px 图层的 Windows `formaview.ico`。每个 ICO 图层按各自布局超采样后单独缩放，不从 256px 图层缩小。

回归命令：`py -3 -B tests/app_icon_tests.py`。测试检查 SVG 与生成器输出一致，并包含底板、立方体三面、棋盘格、取景框和播放头；检查每个 ICO 图层与生成器逐像素一致、四角透明、底板居中，以及各尺寸使用的布局。Windows 资源管理器、任务栏和旧快捷方式可能缓存先前图标；本更改不清理系统图标缓存或重建用户快捷方式。
